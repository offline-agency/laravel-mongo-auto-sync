# Laravel Mongo Auto Sync v4

Version 4 of `offline-agency/laravel-mongo-auto-sync` requires PHP 8.4 or later and Laravel 12 or 13.

This package provides a better support for [MongoDB](https://www.mongodb.com) relationships in [Laravel](https://laravel.com/) projects. At low level all CRUD operations are handled by [mongodb/laravel-mongodb](https://packagist.org/packages/mongodb/laravel-mongodb).
